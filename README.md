# CookX · 鲜厨智享

从冰箱里的食材，到餐桌上的每一道菜。

CookX 是原生 Android 智能烹饪助手，串联食材识别、库存管理、菜谱、分步烹饪与锅温感知。

本分支 `feat/competition-demo` 提供可独立运行的手机体验版本：内置「林小厨」厨房，首次打开直接使用，日常操作保存在本机。联网 AI 由手机直接连接阿里云百炼，无需电脑或自建后端。

| 功能 | 使用方式 |
| --- | --- |
| 冰箱管理 | 手动添加、照片识别确认、批次编辑、临期提醒、到期处理 |
| 菜谱与 AI | 30 道内置菜谱、收藏与独立复刻；支持发布时预置在线服务，也可在手机更换配置 |
| 烹饪指导 | 逐步教程、计时、系统/在线语音、语音或文字指令、实际库存扣减 |
| CookX Sense | JDY-31 经典蓝牙测温、温度趋势、火候提醒；另有明确标注的仿真回放 |
| 家庭厨房 | 本机家庭库存、转入食材、共同采购、认领、购买与实际入库 |
| 七日菜单 | 午晚餐预设、用餐人数、忌口、锁定菜、重复上限、预算和营养条件检查 |
| 一起晒菜 | 本机作品、图片、点赞、评论、作品收藏与菜谱复刻 |
| 剩菜与成长 | 剩余食材记录、条件检查、再利用思路、烹饪记录和成就 |

在线结果、内置示例和温度回放各自标明来源。没有网络或密钥时仍可使用本地业务；照片识别失败不会返回预置食材冒充识别结果。

本机社区和家庭内容用于单台设备体验，不跨手机同步。初始食材、作品和烹饪历史为示例内容。鲜度与温度提示是辅助判断，不代表食品安全检测结论。

主线的 Web 与服务端代码保留在 `main`；本分支只交付 Android 体验及其依赖。
