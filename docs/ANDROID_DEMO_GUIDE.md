# Android 体验使用说明

## 安装与首次打开

安装签名 APK。桌面名称为 **CookX 体验版**，包名 `com.smartcooking.app.showcase`，版本 2.2.1（21）。它与正式版 `com.smartcooking.app` 可以共存，也可覆盖更新同证书的 2.2.0 体验版。

打开后直接进入「林小厨」的厨房，无需注册或登录。已有库存、菜谱、家庭、采购、社区、成长记录和七日菜单，操作会在本机保存。初始记录是体验示例，不是实际用户使用记录。

如果手机已安装旧的同包名体验版，通常可覆盖更新。遇到签名不一致时，先备份需要保留的内容，再处理旧安装；不要为了安装而误删正式版。该版本关闭系统自动备份，密钥不随备份迁移。

## 内置在线服务与更换配置

内置服务的安装包打开后即可联网使用 AI 菜谱和图片识别，不需要填写 Key 或部署电脑。「我的 → 体验管理」显示「已内置在线服务」，可点击「检测连接」。如果之前手动保存过配置，会优先保留；选择「恢复内置服务」切回安装包中的默认配置。

以后更换 Key 时打开「更换服务配置」，同时填写 Key 与匹配的兼容接口地址，再保存检测。未内置服务的构建也可按下面步骤配置：

1. 在手机或电脑浏览器打开[阿里云官方获取 API Key 教程](https://help.aliyun.com/zh/model-studio/get-api-key)，进入百炼控制台。
2. 登录阿里云账号，按控制台要求开通服务，选择**华北 2（北京）**地域并创建 API Key。API 调用按账号额度和用量计费，以控制台显示为准。
3. 手机打开 **我的 → 体验管理 → 更换服务配置**，粘贴 Key 及同业务空间的 `/compatible-mode/v1` HTTPS 地址，点击 **保存并检测连接**。普通北京共享接口为 `https://dashscope.aliyuncs.com/compatible-mode/v1`，业务空间 Key 可使用控制台给出的专属地址。该操作发送一个很短的文本请求核对文本模型权限。
4. 显示「AI 服务已连接」后，到 **AI 菜谱** 输入「用番茄和鸡蛋做一道家常菜」，确认返回了可执行步骤。
5. 到 **冰箱 → 识别食材 → 拍照识别/从相册选择**，选择真实食材照片，核对识别清单后再入库。连接检测不等于照片识别已经验证。
6. 烹饪时在工具中尝试「在线播报」。它也使用同一把 Key，但需有对应语音模型权限。

手机直接使用以下接口与模型，无需部署电脑后端：

| 用途 | 模型 / 服务 |
| --- | --- |
| 菜谱生成 | `qwen-plus`，配置的北京地域 OpenAI 兼容 Chat Completions 接口 |
| 照片识别 | `qwen3-vl-plus`，同地域多模态 Chat Completions 接口 |
| 在线播报 | `qwen3-tts-flash`，官方北京共享域名的 MultiModal Generation 接口 |

参考：[文本接口](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions/)、[视觉接口](https://help.aliyun.com/zh/model-studio/vision/)、[在线语音接口](https://help.aliyun.com/zh/model-studio/qwen-tts-api)。模型权限和可用性以百炼控制台为准。

手动填写的 Key 用 Android Keystore 加密后保存在这台手机；仓库不保存真实 Key。内置服务的 Key 以 AES-GCM 加密内容随安装包提供，重新安装仍可使用内置配置。可在体验管理「停用在线服务」；此设置重启后仍有效，不影响本地业务。

仅主动发起在线操作时发送必要内容：菜谱请求包含需求、可用库存和当前烹饪步骤/温度状态；识别发送选定照片；在线播报发送当前步骤文本。用户与家庭数据库不上传到自建服务。

## 建议体验路线

1. **首页 → 冰箱**：查看预置库存和临期食材；打开通知可定位到具体批次，修改或删除后提醒随之更新。
2. **识别食材**：有网络时拍真实照片；无网络时选择「体验示例食材」，页面明确显示「非照片识别结果」。核对数量、日期和储存方式后确认入库。可保留草稿或明确放弃。
3. **AI 菜谱 / 菜谱库**：在线生成一份菜谱，或打开内置菜谱。首页最近菜谱打开原内容，不会重新请求生成。收藏与复刻保存独立副本。
4. **开始指导**：进入分步烹饪，主界面可见语音指令；说「下一步操作」，或在文字指令中输入「下一步」。语音识别需系统识别服务和麦克风权限，系统播报需中文 TTS 语音包。
5. **连接 CookX Sense**：开启手机蓝牙，按原有方式配对 JDY-31，在厨房设备入口选择设备。等待连续有效测量后展示温度与趋势。不要把探头温度当成食物中心温度。
6. **温度备用演示**：没有硬件时，在厨房温度详情打开「仿真回放」。界面标明「物理仿真回放 · 非设备实测」，不冒充现场采集。连接真实硬件前停止回放。
7. **完成烹饪**：选择实际使用的库存批次与数量，再确认完成并扣减。失败时保留原凭证核对/重试；也可明确选择「仅记录完成，不扣库存」。完成后可选择添加剩余熟食记录。
8. **七日菜单**：点击「接受预设并生成菜单」，查看 2 人、7 天午晚餐的组合。保存后逐菜复刻进入备菜，或前往共同采购选择该菜单生成需求。
9. **共同采购**：认领 → 标记购买 → 填写实际收到的数量/单位/储存信息 → 入库。不同单位不自动换算。
10. **一起晒菜 / 厨艺成长**：发布本机作品、点赞评论或收藏作品；查看新增烹饪记录与预置示例记录。

## 断网与恢复

- 冰箱、批次写入、菜谱库、菜单、本机家庭/社区、计时、烹饪记录均不需要电脑或网络。
- AI 请求无法完成时，界面说明打开的是**内置菜谱**，不会声称本次 AI 已生成。照片识别失败时提供手动录入或示例入口，不虚构照片结果。
- 系统语音是否离线可用取决于手机已安装的中文语音包和识别服务。文字指令与步骤按钮始终保留。
- API Key 无效/无权限：检查是否北京地域 Key，模型服务是否开通。额度不足或请求受限：查看百炼控制台。超时：换手机网络后重试。
- 每轮体验前可用 **我的 → 体验管理 → 恢复初始内容** 重置厨房。确认后清除后续库存、作品、草稿和烹饪进度；API Key 保留。
- 不要在正在保存库存、在线生成或连接设备的途中重置。

## 出发前在实际手机核对

充足电量；开启通知、麦克风和所需蓝牙权限；准备手机流量；确认真实 AI 菜谱、真实照片识别、中文语音和 JDY-31 连续读数各成功一次；随后关闭网络再走一次内置菜谱与库存流程。即使有本地备用入口，出发前仍需核对实际手机与硬件。
